# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：講座固有の情報を持たないモデルは、3レベルを知らないと答えるか、一般論から推測することがあった。
- 用語集の正しい意味と比べて気づいたこと：正しくは「基礎（講義内容の確認）」「実装（自分でコードを書く）」「発展（調査や試行）」の3段階。LLMは一般的な知識だけでは講座固有の定義を保証できず、もっともらしい推測をする場合がある。
- 表示できたトークン数（入力 / 出力）：回答の後に入力・出力トークン数が表示されることを確認した。数値は質問や回答によって変わるため、固定値では記載しない。

## 宿題

- 取り組んだレベル：実装
- やったこと：`app/ask.py` に `--chat` オプションを追加した。Gemini の Chat セッションを作成し、同じセッションに続けて質問を送ることで会話履歴を保つ。空入力または EOF で終了でき、従来の単発質問モードも残した。
- 結果：会話セッションへの質問送信とトークン数表示をテストし、全12件のテストが通過した。`uv run python -m app.ask --chat` で対話を開始でき、`uv run python -m app.ask --chat "LoRAとは何ですか？"` のように最初の質問を指定することもできる。
- 気づき・疑問：単発の `generate_content` 呼び出しでは履歴は引き継がれないが、同じ Chat セッションに `send_message` を送ることで文脈を保てる。一方、履歴は実行中のセッションに限られ、プログラムを終了すると失われる。また、会話が長くなると過去の内容も入力に含まれるため、入力トークン数が増える可能性がある。
